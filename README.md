# Student Result Analyzer

A beginner-friendly Python project that analyzes student marks and generates a complete result summary.

## Features

- Accepts student name
- Takes marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Calculates average marks
- Assigns grade
- Shows overall PASS/FAIL result
- Shows subject-wise PASS/FAIL result
- Finds highest-scoring subject
- Finds lowest-scoring subject
- Validates marks between 0 and 100

## Subjects

- Python
- Mathematics
- Data Structure
- Artificial Intelligence
- English

## Technology Used

- Python 3

## How to Run

1. Open `student_result_analyzer.py`
2. Run the program using Python 3.
3. Enter the student's name.
4. Enter marks for each subject.
5. The program will display the complete result analysis.
